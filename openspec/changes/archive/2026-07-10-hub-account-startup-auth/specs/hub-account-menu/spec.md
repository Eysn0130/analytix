## ADDED Requirements

### Requirement: Sidebar footer becomes account trigger
The desktop sidebar SHALL replace the standalone footer settings button with a taller account trigger showing identity and product category.

#### Scenario: Account trigger is rendered
- **WHEN** the sidebar is visible
- **THEN** the footer shows an avatar or initials, username, product category, and a Connect Phone icon control

#### Scenario: Product category is displayed
- **WHEN** the account plan is `normal`, `professional`, or `admin`
- **THEN** the footer displays `普通版` for normal and `专业版` for professional or admin

### Requirement: Account dropdown exposes account actions
The account trigger SHALL open a dropdown inspired by CodexDesktop-Rebuild profile dropdown behavior.

#### Scenario: User opens account menu
- **WHEN** the user clicks the account trigger
- **THEN** the menu includes email, personal account, settings, invite friend, remaining usage, and logout entries with separators matching the reference layout

#### Scenario: User opens settings
- **WHEN** the user selects settings from the account menu
- **THEN** the menu closes and the app navigates to the settings view

### Requirement: Usage and referral are Hub-backed
The account menu SHALL fetch remaining usage and referral data from Hub desktop Bearer endpoints.

#### Scenario: User opens remaining usage
- **WHEN** the user selects remaining usage
- **THEN** the app displays token balance, token limit, and gateway usage summary for the current Hub user

#### Scenario: User opens invite friend
- **WHEN** the user selects invite friend
- **THEN** the app displays the same referral share URL generated by Hub and provides copy/open actions

### Requirement: Logout clears account menu state
The account menu SHALL clear local account state and close account-gated surfaces on logout.

#### Scenario: User logs out from account menu
- **WHEN** the user confirms logout
- **THEN** the app clears local Hub auth, deletes gateway secrets, disables model access, and returns to the login gate
