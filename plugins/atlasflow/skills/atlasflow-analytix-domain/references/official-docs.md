# Official-Document Diagram Guidance

Use official-document diagrams for document drafting, circulation, approval, execution, and archive flows.

Recommended templates:

- 发文办理流程图: `workflow`
- 收文办理流程图: `workflow`
- 请示-批复关系图: `architecture`
- 公文生命周期图: `lifecycle`
- 审核签发流程图: `workflow`
- 公文要素检查图: `workflow`
- 多部门会签流转图: `workflow`

Common nodes:

- `拟稿`
- `审核`
- `会签`
- `签发`
- `登记`
- `分办`
- `承办`
- `催办`
- `办结`
- `归档`

Keep formatting checks separate from content judgment. When the user asks for formal document formatting, point back to the host application's official-document writing tools if available.
