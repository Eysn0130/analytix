# Mature Plugin Drift Table

This table records the current P0 structural drift from mature plugin patterns
to Analytix economic-investigation delivery. It is intentionally case-neutral:
no real names, amounts, conclusions, golden answers, or old evidence are stored
here.

| Mature mechanism | Analytix landing point | Current gap | Fix action / contract |
| --- | --- | --- | --- |
| Data Analytics `index` routes to focused workflows after source/context preflight. | Root and `index` only admit the task, confirm current case and available capabilities, then select one focused owner. | A broad natural-language entry can still make `funds_investigate` look like the default answer owner. | Keep `funds_investigate` as navigator/support; assert `lead_owner_contract` and route Pair Amount, dossier, tracing, visual/report tasks to focused owners. |
| Data Analytics user-context and source envelopes separate source discovery from analysis prose. | `case-context`, scope map, case-project resolution, cleaned/export scope and analysis index become shared workflow context. | Source/case/workbench facts can be mixed into user prose with internal labels. | Keep case/source facts in support summaries and Evidence Ledger; final prose uses current-case business language, not source-envelope labels. |
| Data Analytics report spine requires answer, evidence, caveat and next step. | Economic-investigation spine: 查什么、结论、流水/账户/链路依据、异常、案件意义、不能认定、下一步材料. | Correct totals can still be delivered as a fact-card summary without investigative judgment. | `delivery-qc` / `analysis-critique` block outputs without facts table, anomaly scan, case meaning and evidence actions. |
| Data Analytics visualize/report delivery performs chart/report QA before handoff. | `visual-evidence` and `report-builder` own tables, graph images, report continuation, attachments and rendering checks. | Graph/report answers may describe support data rather than produce a readable artifact. | Require hero deliverable first: evidence table, graph/PNG/JPG, report section or attachment list; support metadata stays hidden. |
| Data Analytics workbook/export delivery creates and validates the actual file before handoff. | `case-workbench` owns explicit cleaned-detail delivery through `export_cleaned_case_data`, while the backend preserves Analytix cleaned headers, field order and row order. | The previous contract described cleaned export behavior but exposed no real plugin tool, so chat could claim delivery without a file. | Require explicit approval, current-case backend export, Analytix-owned output boundary, async job continuation and CSV/XLSX read/signature inspection before delivery. |
| Investment Banking router is only an invocation gate and lead selection layer. | `index`, root skill and command metadata perform focused skill selection. | Old contracts could still say the first internal action is `funds_investigate`. | Remove first-call/default-draft contracts from production paths; smoke checks forbid `funds_investigate` as final owner. |
| Investment Banking lead skill owns memo/deck deliverable depth and final response. | Pair Amount, subject/account dossier, fund tracing, full-case analysis, visual evidence and report builder each own their deliverable. | A support card can tempt the agent to stop after a candidate summary. | Focused skills define Use When / Workflow / Output Contract / Completion Gate; support cards expose only evidence, validation and risks. |
| Investment Banking support workstreams stay hidden behind the client-ready artifact. | Workbench, rank, card renderer, validator and ledger provide support facts only. | Support runtimes previously generated reusable answer paragraphs and card titles could tempt the final writer. | Production frontdoor/destination/ranking runtimes generate no answer draft; `agent-output-compiler` and ordinary card rendering emit bounded support envelopes, while prose rendering is explicitly audit-only. |
| Investment Banking and Public Equity avoid internal synonym leakage in client-ready prose. | Legacy card headings are translated into case-material wording before any user-visible path, and old near-synonyms are blocked as leaks. | Replacing old headings with close synonyms such as generic amount口径 or account-stat labels can still sound like a tool card. | `translateUserVisibleText`, `userVisibleLeakageLabels`, card audit rendering, and destination diagnostics now use conclusion/evidence/action wording such as amount verification, competitive amount explanation, key-account flow, unsupported matters and next investigation action. |
| Public Equity Investing final deliverable is human-readable artifact first. | User sees case material, amount memo, graph, table, report or evidence request, not workflow/debug fields. | Answers can still read like audit checklists. | User-visible language smoke and delivery QC forbid workflow/debug/support-layer terms and require public-security language. |
| Public Equity Investing PM judgment asks what matters, what is uncertain and what action follows. | Economic-investigation judgment asks why the money/account/link matters, what is abnormal, what remains unproved and what to subpoena. | Fact correctness alone can pass older checks. | Professional judgment contracts require anomaly, case meaning, evidence maturity and next investigation action. |
| Public Equity support-layer routing marks support outputs as non-final. | Rank/workbench/funds cards are locator/support evidence for the lead owner. | Rank rows can be mistaken for final Pair Amount. | Pair Amount owner reconciles raw detail, high-confidence dedup, duplicate/evidence-insufficient amount, account/time concentration and evidence actions. |
| Mature plugins use validation gates to reject shallow or unsupported deliverables. | Delivery QC reviews Pair Amount, dossier, tracing, graph/report and attachments. | Old tests rewarded support-card phrases. | Update smoke/model eval markers to reward period, count, amount, table, anomaly, case meaning, unsupported limits and subpoena actions. |
