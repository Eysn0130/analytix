# 公安经侦公文写作

本 reference 用于把已核验资金事实整理成公安经侦材料、公文式报告、专题核验材料、
补证清单和结论复核意见。它不是通用“去 AI 味”指南；目标是事实清楚、证据有界、
表述稳妥、便于继续侦查。

## 材料类型

| 类型 | 适用场景 | 首要目标 |
| --- | --- | --- |
| 快查答复 | 是否有关联、某金额多少、某对象是否出现 | 直接给核验状态、依据和暂不能认定事项 |
| 专题核验材料 | 两方金额、资金去向、金融产品、对公转个人、单线索 | 写清事实、统计范围、异常特征、案件意义和补证动作 |
| 账户/主体画像 | 某卡、某账号、某人、某公司资金研判 | 形成基本情况、账户结构、资金流入流出、重点对手方、异常特征 |
| 研判报告摘要 | 生成报告后的聊天答复 | 先交代报告已生成，再给事实摘要、资金分析、异常特征、边界和建议 |
| 正式研判报告 | 用户要求报告、材料、附件、续写或修订 | 使用公文标题层级和经侦证据语言 |
| 补证/调证清单 | 需要继续追查、调取材料、完善证明链 | 说明调什么、向谁调、证明什么、优先级是什么 |

## 篇章顺序

正式或半正式材料优先使用以下顺序，短答可压缩但不要改变证据逻辑：

1. 核查事项或研判结论。
2. 本次依据与统计范围。
3. 已复核事实：主体、账号、时间、金额、笔数、方向和对手方。
4. 表格、资金链路或附件依据。
5. 异常特征或资金关系判断。
6. 案件意义：资金来源、资金去向、账户角色、受益转移、隐匿规避或补证优先级。
7. 暂不能认定事项。
8. 下一步补证/调证动作。

表格后必须有研判意见。表格只列数字不解释异常、证明价值和证据缺口，不能作为
合格经侦材料。

## 公文式表达

推荐句式：

- `经对已调取银行流水进行梳理，...`
- `已调取流水显示，...`
- `从交易时间、金额、账户分布看，...`
- `该情况对判断双方资金关系、账户角色或资金去向具有补证价值。`
- `但现有材料尚不能证明...，需进一步调取...`
- `建议补调...，用于固定...`

不写：

- `高度重视`、`压实责任`、`形成合力`、`纵深推进`、`取得实效`、`坚实基础`、`强力支撑`。
- `深刻揭示`、`底层逻辑`、`核心密码`、`关键抓手`、`全链路闭环`。
- `结论先说`、`综上所述`、`让我们`、`希望这对你有帮助`、`如需我可以继续`。

## 证据成熟度

用户可见材料只使用以下梯度：

| 标签 | 可写内容 | 禁止升级 |
| --- | --- | --- |
| 已复核事实 | 已由当前案件清洗流水、账户事实或报告复核支持 | 不扩大到未调取期间或未列明账户 |
| 已有流水支持 | 银行流水能证明交易、金额、时间、方向和账户 | 不证明资金性质、实际控制或最终用途 |
| 高可信支持 | 多字段、多表或多工具一致支持同一事实 | 不替代外部证据 |
| 可形成材料候选 | 可写入材料但仍需列明依据和边界 | 不写成最终事实 |
| 线索 | 有交易、字段或图谱提示但证据未闭合 | 不写成确定路径或确定身份 |
| 需复核 | 存在差异、重复、缺字段或竞争金额 | 不选择性引用有利数字 |
| 暂不能认定 | 当前证据不足以支持控制、性质、去向或法律判断 | 不用模糊话术掩盖缺证据 |
| 当前证据不足 | 当前案件材料无法支撑该结论 | 不补猜测、不补旧案事实 |

## 法律敏感降级

银行流水可以证明资金交易事实；一般不能单独证明犯罪构成、主观目的、实际控制、
代持、最终归属、违法所得、洗钱、虚开或犯罪团伙关系。

| 越界表述 | 安全写法 |
| --- | --- |
| `违法所得`、`赃款`、`非法所得` | `资金性质待结合合同、回单、用途说明和外部证据进一步固定` |
| `洗钱事实成立`、`虚开事实成立` | `相关法律评价需结合税务、合同、物流、发票、上下游证据另行判断` |
| `实际控制`、`代持`、`最终归属` | `控制/归属关系尚需开户资料、设备/登录、授权、证言或平台记录固定` |
| `犯罪团伙`、`共同犯罪`、`跑分团伙` | `人员/账户协同线索，需结合身份、通讯、设备、平台和证言材料` |
| `坐实`、`锁定`、`认定` | `已有材料提示/支持，仍需按证据成熟度表述` |

## 表后研判

每张金额表、Top 表、资金链路表、续调清单后，至少补一段：

- 表中最关键的时间、金额、账户或对手方集中现象；
- 该现象对资金来源、去向、账户角色、资金关系或补证优先级的意义；
- 现有材料还不能证明什么；
- 下一步调取什么材料用于固定。

不要让表格成为最终结论，也不要把附件目录当作研判意见。
