# 两方金额成稿参考

用于把支撑事实写成办案人员能直接使用的小研判材料。只在成稿或质检时读取。

## 默认结构

自然问题不套长模板。优先使用：

1. 两三段连贯研判：金额、期间、账户、集中转账、集中交易以外往来、资金意义。
2. `金额核对表`。
3. `重点交易表`。
4. 短的 `证明力固定/补证建议`。

只有用户明确要正式报告、附件或完整说明时，才展开更多标题。

## 质量门

成稿前检查：

- 换掉任何工具卡标题、support 字段、英文状态词、内部字段和工程词。
- 不写 `按当前案件、未限定时间和账户口径核验`、`全期间同名收款人`、`口径提示`。
- 不写 `簇`、`cluster`、`focus_cluster`、`outside-cluster`。
- 不把边界说明写成主体内容；边界要服务于金额、异常、资金意义和补证动作。
- 如果换掉姓名和金额后还能适用于另一个案子，说明太模板化；补入本案账户、时间、
  备注/类型、集中转账、重复差异和已见承接事实。

## 经侦表达替换

| 不给用户看的说法 | 用户可见表达 |
| --- | --- |
| focus cluster / focused cluster | 主要集中转账 / 集中交易组 |
| outside-cluster rows | 集中交易以外逐笔往来 |
| raw amount | 原明细金额 |
| effective amount | 复核后有效金额 |
| dedup | 重复风险复核 |
| supported / candidate | 已有流水支持 / 线索 |
| direct / candidate account | 已登记账户 / 待核账户线索 |
| source envelope / validation state | 数据来源与统计范围说明 / 核验意见 |

## 示例句式

```text
经已调取流水复核，YYYY年MM月DD日至YYYY年MM月DD日期间，
A 通过 X 个付款账户（账号...）向 B 的 Y 个收款账户（账号...）
转账 N 笔，复核后有效金额 X 元。
```

```text
其中 YYYY年MM月DD日集中转账 N 笔、金额 X 元，占复核后有效金额的 X%。
该部分金额集中、时间连续，属于后续资金穿透和回单固定的优先对象。
```

```text
集中交易以外另有 N 笔、金额 X 元，分布于 YYYY年至YYYY年，摘要/类型显示
还款、汇款、理财或其他用途线索，说明双方并非只有单日大额往来，需结合回单、
双方说明和余额连续性判断资金性质。
```

```text
证明力固定建议：在已调取流水中导出上述逐笔明细，核对交易编号、回单号、
余额连续性和成功状态；外部补取开户/控制材料、用途合同或借据、理财/订单/KYC
记录，用于证明资金来源、用途和实际控制关系。
```
